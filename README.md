# Capital Flop

The live drop in capital from Elon Musk to a beggar, with professions and business owners on one scale.

## Download the Android app

**[Download Capital-Flop.apk](https://github.com/boss974829/capitalism/raw/refs/heads/main/Capital-Flop.apk)** (v1.0)

Package: `app.capitalflop`

Open the file on an Android phone and allow install from this source when asked. This is a sideload APK, not a Play Store listing. The drop, race, jobs, and owners screens work offline. Fonts look sharper when the phone is online.

## What it shows

- **The drop.** One ladder from Elon to a beggar. Width is linear, so the scale is true and almost everyone disappears.
- **Race.** A paycheck against the clock.
- **Jobs.** Professions on the same scale.
- **Owners.** Business owners.

Numbers are approximate anchors around 18 Oct 2026, not a live market feed.
